# 발췌 스튜디오 1.0.3 (Marinara Engine 확장)

Marinara Engine 개인 확장입니다. (2.4.x ~ 2.5.1까지 호환 확인) 채팅에서 드래그한 문장을 **발췌 카드**로 꾸며 PNG로 저장합니다. 형광펜·밑줄·검열·단어 치환·종이 질감 배경·작품명 표기를 지원하고, 결과물은 브라우저 안에서 캔버스로 그려 다운로드 폴더에 저장됩니다. 서버에는 아무것도 올리지 않습니다.

브라우저 어디서나 쓰는 크롬 확장판은 [excerpt-studio-web](https://github.com/boricha417/excerpt-studio-web)에 따로 있습니다.

## 사용 순서

1. 채팅 메시지에서 글을 **드래그**합니다. 선택 끝에 `❝ 발췌` 버튼이 뜹니다. 메시지 바깥(입력창, 설정 등)의 글에는 뜨지 않습니다.
2. 버튼을 누르면 스튜디오 창이 열립니다. 왼쪽은 설정, 오른쪽은 미리보기입니다.
3. 미리보기에서 글자를 드래그한 뒤 형광펜·밑줄·검열 색을 고르면 그 부분에 마크가 들어갑니다.
4. `PNG 저장`을 누르면 `발췌_날짜_시각.png`로 저장됩니다.

## 설정 항목

| 묶음 | 항목 |
| --- | --- |
| 글자 | 크기(슬라이더 또는 숫자 직접 입력), 폰트, 정렬(왼쪽·가운데·오른쪽·양쪽), 글자색, **대사 색상**(따옴표 "…" 안의 글만 다른 색, 켜고 끄기) |
| 형광펜 · 밑줄 · 검열 | 형광펜 4색(노랑·초록·분홍·파랑) + 직접 선택 1색, 밑줄은 같은 색을 짙게, 검열(검은 마크), 마크 지우기. 형광펜↔밑줄은 모드 버튼으로 전환합니다. 직접 선택 견본은 모서리의 `C` 뱃지를 누르면 색을 고를 수 있고, 고른 색은 기억되며 그 견본으로 칠한 부분은 색을 바꾸면 같이 바뀝니다. |
| 치환 | `찾기 → 바꾸기` 규칙을 여러 개 둡니다. 이름 바꾸기, 호칭 바꾸기 용도입니다. 마크는 바뀐 글 위치를 따라가고, 치환된 단어 위의 마크는 바뀐 단어 전체를 덮습니다. 따라갈 수 없는 마크는 사라지며 안내가 뜹니다. |
| 작품 정보 | 작품명(기본은 채팅방 이름)과 작가(기본 `MARINARA`). 고쳐 쓰면 다음에 열 때도 그대로입니다 — 작품명은 **그 채팅방에서만**, 작가는 모든 방에서. 기본값과 다를 때 입력칸 옆에 `↺`가 나타나며 누르면 채팅방 이름 / `MARINARA`로 되돌아갑니다. 체크를 끄면 카드에서 빠집니다. |
| 배경 | **질감 4종** 화이트·다크·크림·크라프트 × **무늬 4종** 종이 질감·줄노트·모눈·없음, 또는 **단색**, 또는 **기기 이미지**(불러온 뒤 어둡게·밝게 겹치기 가능). 줄노트는 글줄 간격에 맞춰 그립니다. |
| 카드 | 폭, 모서리 둥글기(기본 16px), 높이 자동/직접, 직접일 때 본문을 위쪽/가운데 정렬 |

설정은 브라우저에 저장되어 다음에 열 때 유지됩니다(기기·브라우저별).

## 폰트

- 목록에는 **기본(페이지 폰트)**, **리디바탕**, 그리고 마리나라에 설치된 폰트(설정의 폰트 메뉴로 올린 것, 구글 폰트 포함)가 나옵니다.
- **리디바탕**은 마리나라 폰트 폴더에 리디 폰트가 있으면 그것을 쓰고, 없으면 jsDelivr(noonnu 미러)에서 한 번 내려받아 등록합니다. 약 724KB이고 처음 한 번만 받습니다. 인터넷이 안 되면 명조 계열로 대신 그립니다.
- 마리나라의 보안 정책(CSP)이 외부 폰트 파일을 직접 막기 때문에, 파일을 받아 메모리에서 등록하는 방식을 씁니다.

## 알아둘 점

- 저장되는 PNG는 미리보기와 같은 배치로 캔버스에 다시 그린 것입니다. 폰트가 아직 로드 중이면 저장 버튼이 잠시 기다립니다.
- 이미지 배경은 저장 결과에 포함되지만, 다음에 열 때 다시 불러와야 합니다.
- PC·안드로이드 크롬에서 확인했습니다.

## 확장이 기대는 화면 표식

- 메시지 영역: `[data-message-id]` 안의 선택만 발췌 대상으로 봅니다.
- 설치 폰트 목록: `GET /api/fonts`
- 채팅방 이름: `localStorage["marinara-active-chat-id"]` + `GET /api/chats/:id`

엔진이 이 구조를 바꾸면 해당 자리만 손보면 됩니다.

## 설치

1. **설정 → 고급 → 위험 구역**에서 "외부 확장 가져오기 허용"을 켭니다.
2. **설정 → 애드온 → 외부 확장**에서 이 저장소의 zip 또는 폴더(`manifest.json`, `extension.js`, `extension.css`)를 가져옵니다. GitHub 확장 관리자 확장을 쓰면 저장소 주소를 등록해 업데이트도 받을 수 있습니다.
   설치용 zip은 저장소에 올려 둔 `발췌 스튜디오_v1.0.3.zip`입니다(파일을 열고 **Download** 버튼). 저장소 전체를 "Download ZIP"으로 받으면 폴더가 한 겹 더 있어 바로 설치되지 않습니다.
3. 가져온 확장은 꺼진 상태로 들어옵니다. 코드 해시를 확인하고 **승인 → 활성화**합니다. 코드가 바뀔 때마다 다시 승인해야 합니다.

이 확장은 `full_page_access` 권한을 씁니다. 드래그 감지와 이미지 생성은 샌드박스 안에서 할 수 없어서입니다. 페이지에 보이는 것을 읽고 바꿀 수 있는 권한이므로 코드를 확인한 뒤 승인하세요.

## 버전 이력

- 1.0.3 — 형광펜·밑줄 색 견본에 다섯 번째 "직접 선택" 견본 추가. 모서리의 `C` 뱃지를 누르면 색을 고르고, 고른 색은 기억되며 그 견본으로 칠한 부분은 색을 바꾸면 같이 바뀝니다(밑줄은 기본 4색과 같은 규칙으로 색상은 두고 명도만 내린 짙은 색).
- 1.0.2 — 고쳐 쓴 작품명·작가를 기억합니다(작품명은 채팅방별, 최근 100개 방). 채팅방 이름·기본 작가와 다를 때 입력칸 옆 `↺`로 되돌릴 수 있습니다. 채팅방 이름은 목록 대신 그 방 하나만 읽습니다.
- 1.0.1 — NBSP가 섞인 글 저장 시 멈춤, 이모지 뒤 치환·마크 위치 어긋남, 모달을 열 때마다 정리 항목이 쌓이던 문제 수정.
- 1.0.0 — 첫 공개.
